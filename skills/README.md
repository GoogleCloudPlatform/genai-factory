# GenAI Factory Skills

This directory contains skills for AI agents working on the GenAI Factory repository. These skills provide context, guidelines, and workflows for agents to perform specific tasks on the factories, their stages, tests, and tooling.

## Available Skills

- **[release-process](./release-process)**: Guide for cutting a new release of the GenAI Factory repository. Use this skill when asked to create, prepare, or draft a new release.
