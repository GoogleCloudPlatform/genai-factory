# GenAI Factory Skills

This directory contains skills for AI agents working on the GenAI Factory repository. These skills provide context, guidelines, and workflows for agents to perform specific tasks on the factories, their stages, tests, and tooling.

## Available Skills

- **[contributing](./contributing)**: End-to-end workflow for contributing to GenAI Factory: triaging GitHub issues, developing factory and stage changes, validating with pre-commit and pytest inventories, optionally verifying end to end on a real GCP project, and submitting sanitized Pull Requests. Use when addressing a GenAI Factory GitHub issue, changing a `0-prereqs` or `1-apps` stage, adding a new factory, or preparing a branch for a pull request.
- **[release-process](./release-process)**: Guide for cutting a new release of the GenAI Factory repository. Use this skill when asked to create, prepare, or draft a new release.
